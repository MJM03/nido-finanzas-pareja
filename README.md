# Nido — Finanzas en pareja

Aplicación web local para organizar ingresos, gastos, ahorro y mercado compartido.

## Cómo abrirla

Abre `index.html` en cualquier navegador moderno. No necesita instalación, servidor ni conexión a internet.

Los datos se guardan automáticamente en el almacenamiento local del navegador.

## Funciones

- Panel con ingresos, gastos, ahorro y dinero disponible.
- Distribución configurable del presupuesto mensual.
- Lista de mercado compartida con cantidades y precios.
- Registro de ingresos extra y gastos.
- Persistencia local y diseño adaptable a celular.

> Las recomendaciones son orientativas y no sustituyen asesoría financiera profesional.
